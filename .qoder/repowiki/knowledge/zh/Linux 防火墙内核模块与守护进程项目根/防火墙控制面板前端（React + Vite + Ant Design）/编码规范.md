- REST 调用统一走 `api/client.ts` 的 `apiFetch` / `apiFetchRaw`，禁止直接调用 `fetch`，错误一律抛出带 `kind` 字段的 `ApiError`。
- 服务端路径字面量集中在 `api/endpoints.ts`，客户端只接收已拼接好的 path，避免在各处散落 `/api/v…` 字符串。
- 401 响应不分散处理：`client.ts` 触发 `emitUnauthorized()`，`AuthProvider` 订阅后统一登出跳转。
- 实时数据通过 `SseProvider` 暴露的 `useSseDomain(domain)` 取 `{value, seq}`，再交给 `useLiveData` 与 REST 轮询合并，视图不感知数据来源。
- Provider 嵌套顺序在 `App.tsx` 中固定声明，注释明确标注两条硬约束（NotificationProvider 需在 AntdApp 内、SseProvider 需在 AuthProvider 内）。
- 组件与 hook 采用「小职责单文件」组织：每个状态态（LoadingState/ErrorState/EmptyState）和每个领域 hook（useAsync/useLiveData/useSse/useHotkey 等）独立成文件。
