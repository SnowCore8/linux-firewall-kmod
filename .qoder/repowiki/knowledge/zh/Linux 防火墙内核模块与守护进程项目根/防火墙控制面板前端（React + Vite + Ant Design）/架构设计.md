模块以 `src/main.tsx` 为入口挂载 React 树并注册 Service Worker；`src/app/App.tsx` 作为 Provider 组合根，按固定嵌套顺序注入 ThemeProvider → AntdApp → ErrorBoundary → AuthProvider → NotificationProvider → SseProvider → RouterProvider，依赖方向单向向外。

- 路由层：`app/router.tsx` + `app/nav.ts` 定义 hash 路由（因后端 `/static/` 下无 catch-all），视图集中在 `views/`（Dashboard、Analysis、Bans、Jails、Logs、Risk、ThreatFeeds、Whitelist、Settings、Ddos、Login）。
- API 层：`api/client.ts` 是唯一的 fetch 封装，统一信封解包、超时、AbortSignal、401 广播（`onUnauthorized`）与 `ApiError` 分类（network/timeout/unauthorized/business/http/parse/aborted）；`api/endpoints.ts` 集中路径常量，`api/types.ts` 共享响应类型，各业务文件通过 `auth.ts` 注入 Authorization 头。
- 实时层：`providers/SseProvider.tsx` 维护全局唯一 `/api/v2/events` 连接，按域（stats/bans/jails/whitelist/rates）分发快照；`hooks/useLiveData.ts` 用 seq 仲裁 SSE 帧与 REST 轮询谁更新，视图只消费单一值而不关心来源。
- 状态与 UI：`components/state/*` 提供 Loading/Error/Empty/RealtimeBadge/StaleNotice 等通用态；图表走 `components/charts/BaseChart.tsx` + `lib/charts.ts` 封装 ECharts；通知由 `NotificationProvider` 经 Antd App.useApp() 弹出。
- 构建契约：`vite.config.ts` 输出到 `build/obj/frontend`，`base=/static/`、`assetsDir=''`、固定文件名（`app.js`），供 Go 端 `go:embed` 打包进二进制；开发期代理 `/api` 到 `http://127.0.0.1:9119`。
- PWA：`public/sw.js` 由守护进程在根作用域 `/sw.js` 单独提供，前端仅注册失败静默忽略。
