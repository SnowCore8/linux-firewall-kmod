本模块按职责划分为三个并列子目录：
- `config/`：以扁平的 YAML 文件组织守护进程与各外部服务（apache/nginx/traefik/docker/mysql/redis/postfix/dovecot/vsftpd/frp/wordpress）的配置；`default.yaml` 是核心默认值，通过 `defaults` + `jails` + `webui` + `ddos` + `threat_feeds` 等顶层键分层，其余 `*.yaml` 为各服务的 jail 定义；`logrotate/firewall-daemon` 与 `modules-load.d/firewall.conf` 提供系统级日志轮转与内核模块加载配置。
- `grafana/`：`firewall-dashboard.json` 是 Grafana 导入型仪表盘（uid=`firewall-daemon`），`alert-rules.yaml` 是 Prometheus alerting rule group，两者均直接引用 `/metrics` 产出的 `firewall_*` 指标名，构成“守护进程 → Prometheus → Grafana”的观测链路。
- `.github/`：`workflows/ci.yml` 是主流水线，拆分为 lint / frontend / build / e2e / test 五个并行或串行的 job，分别驱动 clang-format/gofmt/shellcheck/yamllint、Vite 前端构建、Go+内核模块编译、Playwright E2E 与 pytest 测试；`scripts/` 下含 Node.js 编写的 dispatch/route/patrol 工具及其 `.test.mjs`；`CODEOWNERS`、`ISSUE_TEMPLATE/`、`PULL_REQUEST_TEMPLATE.md` 维护协作规范。
依赖方向单向向外：本模块不引入业务代码，仅被 Makefile、CI 和部署流程消费。
