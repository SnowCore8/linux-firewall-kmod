- 每个外部服务的独立配置以独立的 `*.yaml` 文件放在 `config/` 根目录下，由 `default.yaml` 提供全局 defaults 与 jail 模板。
- Grafana 仪表盘与告警规则中的 PromQL 表达式直接使用守护进程 `/metrics` 暴露的 `firewall_*` 指标名，保持与源码产出逐字对齐。
- GitHub Actions 流水线将 lint、frontend、build、e2e、test 拆分为独立 job，并通过 `needs` 建立依赖顺序，同时使用 actions/cache 缓存 Go mod、pip、ccache 与 npm 依赖。
- 需要 root 权限的内核交互步骤（insmod/rmmod、启动 daemon）统一通过 `sudo bash scripts/e2e-daemon.sh {probe,start,stop,env}` 封装，避免在 workflow 中散落特权命令。
