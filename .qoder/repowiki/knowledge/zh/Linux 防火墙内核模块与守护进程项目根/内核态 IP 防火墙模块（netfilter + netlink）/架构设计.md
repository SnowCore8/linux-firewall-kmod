模块按数据所有权切分为多个子系统，每个 fw_*.c 只触碰自己拥有的数据结构，由 Makefile 中的 firewall-y 列表组装成单一 kernel module `firewall.o`。

- 入口与生命周期：`fw_main.c` 定义全局单例 `fw_info` 与模块参数，init 顺序严格为「参数校验 → 各子系统表/锁初始化 → netlink → 状态恢复 → 本机地址重建 → netdev notifier → procfs → 注册 v4/v6 netfilter hook」；exit 逆序清理并以 `shutting_down` 原子位作为热路径第一道放行门。
- 核心数据结构集中在 `fw_types.h`：封禁表按 prefix_len 分层（全长层复用固定桶数组，短前缀层用内嵌小数组），白名单含精确桶+子网链，速率表使用 per-CPU 槽（`FW_RATE_CPU_SLOTS=512`，分块申请避免 per-CPU 内存超限），统计与分析表同样 per-CPU 累积后 flush。
- 并发模型：除 `rate_locks[bkt] → rate_slot_lock` 这一对嵌套外，任意两把 spinlock 不得嵌套；删除走 hlist_del_rcu + call_rcu，读侧 RCU；`fw_compat.h` 提供内核版本兼容封装。
- 对外契约：`fw_netlink.c` 与 `fw_procfs.c` 分别实现 netlink 控制面与 /proc/firewall/* 文本接口，协议格式来自 `contract/generated/netlink_uapi.h` 与 `procfs_uapi.h`（Makefile 通过 `-I$(src)/../../contract/generated` 引入，模块只读不改）。
- 钩子点：`fw_hook.c` 在 NF_INET_PRE_ROUTING/NF_INET_LOCAL_IN 等位置调用 ban/wl/rate/stats 判定，最终返回 ACCEPT/DROP。
- 辅助子系统：`fw_local.c` 维护本机地址集合（开放寻址哈希集，支持扩容），`fw_ports.c` 维护受保护端口位图（daemon 下发，空指针语义为全端口受保护），`fw_rate.c` 做 EWMA 平滑与窗口滚动选举，`fw_state.c` 持久化到 state_file，`fw_stats.c` 聚合 UDP/ICMP 分布与直方图。
