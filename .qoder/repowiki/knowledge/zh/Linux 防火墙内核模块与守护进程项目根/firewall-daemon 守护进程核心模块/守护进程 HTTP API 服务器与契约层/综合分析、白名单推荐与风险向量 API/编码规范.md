- Handler 入口先检查 h.db == nil，未初始化时统一用 WriteServiceUnavailable 返回「history database not initialized」或对应中文提示，再 return。
- 路径参数 ip 一律经 r.PathValue 取后使用 netip.ParseAddr 校验，非法地址以 httpcontract.Code40006 返回。
- 可选字段（risk/reputation/prediction）在契约中声明为指针类型，缺失记录或底层查询失败时返回 nil，由前端渲染为 null 而非零值。
- 统计口径严格复用兄弟端点的实现：active_attacks 复用 port-scanners/service-probes 的内核快照、anomalies_count 复用 ipAnomalies、collaborative 复用 DetectCollaborativeAttacks 的同窗口同阈值。
- TotalRisk 采用七维浮点加法模型（Failure+Ban+Scan+Bruteforce+DDoS+Geo+Cluster），在 riskVectorResponse、RiskVectors、ListRiskVectors 多处重复计算以保证排序与展示一致。
- 分页/上限通过常量集中声明（analysisBanHistoryLimit=100、analysisPredictionLimit=100、analysisCollaborativeLimit=1000），并与兄弟端点逐字对齐以避免口径分叉。
