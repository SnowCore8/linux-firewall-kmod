本模块是 `daemon/internal/http` 包下的三个 handler 文件，统一挂载在 `APIHandlers` 上，依赖方向单向向外：HTTP 层 → `internal/persist`（数据库查询）、`internal/analysis`（协同攻击检测与攻击预测）、`internal/bans`（全局白名单镜像），并通过 `internal/httpcontract` 返回统一错误码。
- analysis.go：实现 GET /api/v2/analysis/summary 与 /api/v2/analysis/ip/{ip}，组合威胁等级（复用 stats 的 buildThreatLevel）、活跃攻击数（端口扫描+服务探测）、行为离群数、协同攻击窗口数、Top10 风险 IP、单 IP 的风险向量/封禁历史/信誉/预测/白名单标记；所有子系统缺席时按契约字段为 null 或空数组降级。
- recommendations.go：实现 GET /api/v2/recommendations/whitelist，基于 ban_events 表按 IPv4 /24、IPv6 /48 聚合频繁临时封禁的子网，输出带 confidence 分档的白名单建议列表。
- risk.go：实现 GET /api/v2/risk/vectors[:ip] 与 /api/v2/risk/events/:ip，直接透传 persist.RiskVectorRow 并计算七维 TotalRisk 之和。
响应结构体（AnalysisSummaryResponse、WhitelistRecommendation、RiskVectorResponse 等）与 `httpcontract` 契约同名同字段，作为 HTTP 层与前端之间的稳定边界。
