- 路由注册全部采用 `s.HandleFunc(httpcontract.Route*, RequireAuth(username, password, lockout, handler))` 形式，将认证中间件作为外层装饰器，避免 handler 内部再判断方法或鉴权状态。
- 可选依赖字段以函数指针或接口形式注入（如 `getCurrentConfig func() *config.Config`、`getRateSamples func(n int) []telemetry.RateSample`、`ThreatFeeds *threatfeeds.FeedManager`），缺失时返回 nil 并让 handler 降级为「无数据」而非 panic。
- 需要读当前配置或活跃 jail 参数的 handler 通过 `currentConfig()` / `currentJailParams()` 辅助函数现取快照，以响应热重载后的最新值，而不是使用构造时的静态副本。
- 对契约未定义业务错误码的分析类路由（ban-effectiveness / ban-duration-histogram / attack-geo），在数据库不可用或查询失败时返回 200 + 空读数 + summary，仅在服务端记录日志，不向上抛出 50002/50003。
