模块由三层组成：
- server.go 定义 `Server` 结构体与 `Config`，封装 `net/http.Server` + `http.ServeMux`，提供 `Start/Stop/Addr/Handle/HandleFunc` 生命周期与连接数查询；通过 `connectionLimiter`（基于 `sync.RWMutex` 计数）实现全局并发上限，并在最外层包裹 `securityHeaders`，使限额拒绝走 `http.Error` 绕过中间件。
- routes.go 定义 `APIConfig` 聚合依赖（DB、SSEBroker、Metrics、KernelBan/Whitelist/Config、AuthLockout、JailController、threatfeeds 等），并通过 `NewAPIHandlers` 注入到 `APIHandlers`；`RegisterRoutes` 集中把 `httpcontract.Route*` 常量映射到 `RequireAuth(...)` 包装后的 handler，按功能域分块注释（健康探针、指标/SSE、封禁、jail、配置、白名单、速率、统计、风险引擎、日志、威胁情报、综合分析）。
- handlers.go 聚焦「历史库分析面」handler（recidivism/reputation/periodic/collaborative/network/attack-predictions/ban-duration-recommendations/threshold-recommendations/ban-effectiveness/ban-duration-histogram/attack-geo），遵循包注释约定的两条纪律：载荷一律使用 analysis_payload.go 的具名 struct，契约未编 codes 的路由在 200 信封内降级而非返回业务错误码。
依赖方向单向向外：本包仅消费 internal 子包（config/persist/telemetry/threatfeeds/httpcontract），不反向被它们引用。
