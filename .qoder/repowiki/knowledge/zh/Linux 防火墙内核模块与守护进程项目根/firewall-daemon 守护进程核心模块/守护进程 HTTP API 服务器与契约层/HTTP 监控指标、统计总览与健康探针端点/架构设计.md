本模块是 `daemon/internal/http` 包内的三个独立 handler 文件，分别对应三类只读观测面：
- `metrics.go`：自实现的轻量指标容器 `Metrics`，以 `sync.RWMutex` + `atomic.Int64` 维护 counters/gauges 两张 map，`ServeHTTP` 按 Prometheus text/plain v0.0.4 协议输出；通过 `Counter(name)` / `Gauge(name)` 懒加载命名指标。
- `stats.go`：`APIHandlers.Stats` 与 `Heatmap` 装配 `StatsResponse`，聚合内核快照（`telemetry.Snapshot`）、历史库 ban_events（`persist.BanActivity`）、进程内失败尝试（`config.GetJailStats`）与 DDoS 事件（`kernel.CounterDdosEvents`），并内置 `windowCache` 对「今日 / 近 5 分钟」两个时间窗口做 30s TTL 缓存，避免首屏三次 SQL；威胁等级由 `buildThreatLevel` 三路信号（PPS 倍率、封禁表占用率、recent bans）取最大值分档到 safe/low/medium/high/critical。
- `health.go`：唯一使用裸 JSON（不经 `WriteSuccess`）的端点，状态码直接表达就绪语义（200/503），载荷 `RuntimeSnapshot` 字段与线上契约类型一一对应，就绪判据仅依赖 `telemetry.Lease == LeaseHeld`。
依赖方向单向向外：读取 `analysis`、`bans`、`config`、`kernel`、`persist`、`telemetry`，不反向依赖路由注册或业务写入路径。
