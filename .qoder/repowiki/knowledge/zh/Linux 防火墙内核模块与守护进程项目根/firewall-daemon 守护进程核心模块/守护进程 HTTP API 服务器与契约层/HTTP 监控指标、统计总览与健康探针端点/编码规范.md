- 对外暴露的 handler 方法统一接收 `(w http.ResponseWriter, r *http.Request)` 并通过 `WriteSuccess`/`writeJSON` 写出响应体，metrics 端点例外地自行设置 Content-Type 并按行拼接 Prometheus 注释头。
- 跨组件共享的计数通过 `atomic.Int64` 值对象 + `sync.RWMutex` 保护 map 的读写分离：先 RLock 快速命中，未命中再升级 Lock 做 double-check 插入。
- 可选外部依赖（`h.db`、`h.getKernelSnapshot`、`h.kmodPresent`、`h.metrics`、`h.kernelVersion`）一律以 nil 检查短路返回零值，保证 handler 在链路未装配时仍可返回部分数据而非 panic。
- 时间窗口计算统一基于本地时区自然日：`startOfToday` 用 `t.Location()` 构造 00:00，趋势标签用 `dayLabel = "01-02"` 格式，避免 UTC 导致的跨日错位。
- 前端可见的枚举字符串（threat level、status、lease state）以包级常量或切片集中声明，并与前端 `types.ts` 逐字保持一致，注释中显式标注契约来源。
