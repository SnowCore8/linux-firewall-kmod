本模块以 `src/daemon/internal/httpcontract/http_contract.go` 作为唯一真相源：所有 REST/SSE 路由的 Pattern、Handler 符号名、认证级别、返回类型、HTTP 状态码映射以及安全响应头都在此生成文件中声明，并由 `contract/verify_http.py` 校验 routes.go 中的注册串与之完全一致。
- `http/server.go` 创建 `Server`，包装 `net/http.Server`，在外层套安全头中间件、内层套连接配额 limiter（配额满直接 503，不经过 mux 以避免 CSP 缺失）。
- `http/routes.go` 消费 `httpcontract.Routes` 常量与 `Route` 表，将每个条目注册到 `ServeMux`；子模块（core_routing、analysis_recommendations、metrics_stats_health）各自实现对应 handler 函数，但不得再手写路径字面量或业务码。
- 统一信封（code/data/message）、业务码枚举（Code40001…Code50003）与 Code→HTTP 状态映射在契约中定义，被各子模块的 handler 共享引用，保证错误语义跨端点一致。
- SSE 两条流（events、logs/stream）的连接上限、心跳间隔与事件名也在契约中声明，供 sse.go 与各发布侧使用。
