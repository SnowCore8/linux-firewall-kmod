- 所有 HTTP 路由的 METHOD /path 字符串、Handler 符号名、认证级别与返回类型都从 httpcontract 包导入，禁止在 handlers.go 等实现文件中手写字面量。
- 业务错误统一使用 httpcontract 中定义的 CodeXXXXX 常量并通过统一信封返回，HTTP 状态码由 CodeHTTPStatus 映射决定而非 handler 自行设置。
- SSE 流的路由必须声明 MaxConnections、Events 与 KeepaliveSecs，且事件名必须与 httpcontract 中 SSEEventNames* 列表逐字一致。
- 安全响应头（X-Content-Type-Options、X-Frame-Options、CSP、Cache-Control）的值取自 httpcontract.SecurityHeaders，实现侧不得硬编码头名字符串。
