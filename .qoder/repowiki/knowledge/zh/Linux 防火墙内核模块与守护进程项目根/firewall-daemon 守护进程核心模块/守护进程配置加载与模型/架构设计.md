模块按职责拆分为若干单文件：
- `types.go` 定义 `Config`、`Jail`、`DdosConfig`、`WebuiConfig`、`CapacityConfig`、`RiskEngineConfig`、`ThreatFeedsConfig` 等运行时结构及 `Default()` 默认值工厂。
- `parser.go` 通过 `gopkg.in/yaml.v3` 把 YAML 解码到内部 `yaml*` 结构（字段全用指针区分「未给出」与「显式零值」），再按 defaults → jails → ddos → webui → trusted_ips → capacity → threat_feeds → geoip 的顺序调用 `applyXxx` 函数增量写入 `cfg`；`parseConfigFrom` 是文件与目录两条路径的共同入口。
- `loader.go` 提供 `ParseConfigFile` / `LoadConfigDirectory`，负责路径校验、`.yml/.yaml` 枚举、字母序 + `_` 前缀运行期覆盖文件最后合并，并在失败时通过 `saved := *cfg` 做整份回滚保证原子性。
- `credentials_env.go` 在 YAML 应用成功后以 `FIREWALL_METRICS_USERNAME/PASSWORD` 环境变量覆盖凭据，实现「环境变量 > YAML > Default()」优先级且不落盘。
- `args.go` 手工解析 `-c/-C/-d/--no-strict/--rollback` 等 CLI 参数。
- `path.go` 提供 `ValidateAndNormalizePath`，统一拦截 `..`、URL 编码绕过、shell 元字符、超长路径与符号链接逃逸。
- `logging.go` 使用标准库 `log/slog` 输出加载期告警，避免依赖上层日志子系统。
- `jails_api.go` 维护包级 `activeJails` 切片与 `jailStats` map，通过 `sync.RWMutex` 暴露 `SetActiveJails/GetActiveJails/UpdateJailStats` 供执行体与 HTTP API 共享运行期状态。
- `kernel_view.go` 将 `Config` 投影为 `contract.SetConfig`，仅携带内核契约中存在的位，其余由内核拒绝位图反馈。
依赖方向单向向外：本包被 daemon 组合根消费，不反向依赖 HTTP/执行层；仅通过 `internal/contract` 与内核 ABI 解耦。
