模块按「执行体编排 / 主链路装配 / 基础设施」三层组织：
- 编排层：`supervisor.go` 提供 `Supervisor`，按登记逆序串行关停各执行体，保证上游先于下游停稳；`shutdown.go` 提供线程安全的 `Shutdown` 令牌（sync.Once + channel）。
- 主链路层：`executor.go` 的 `InboundExecutor` 是单 goroutine 独占的驱动循环，通过 `unix.Poll` 同时等待 inotify fd 与信号 fd，每轮依次跑到期维护、排空反向指令、桥接 Web UI 启用状态、补挂待重挂源、poll、分派信号/inotify 事件；`pipeline.go` 把 ingest/detect/logparse/decision 四段装配成无锁流水线，产出纯内存的 `BanIntent`，不直接碰 netlink。
- 基础设施层：`directives.go` 定义内核→执行体的反向指令通道（CONFIG_CHANGE / COMMAND_REJECTED），非阻塞投递、每轮排空；`file_reloader.go` 实现 `ConfigReloader`（Reload/Rollback），从默认配置起步再合并文件；`timers.go` 提供固定容量单调时钟 `TimerTable`，避免挂钟回拨与事件洪泛导致的漂移。
依赖方向单向向外：本包依赖 `internal/config`、`internal/ingest`、`internal/logparse`、`internal/decision`、`internal/bans`、`internal/contract`，并通过接口（`BanSink`、`StatsSink`、`MaintenanceHooks`、`ConfigReloader`、`KernelConfigPusher`、`JailEnabledSource`、`JailSnapshotListener`、`DecisionFacts`）把副作用与外部事实注入，使主链路可单测。
