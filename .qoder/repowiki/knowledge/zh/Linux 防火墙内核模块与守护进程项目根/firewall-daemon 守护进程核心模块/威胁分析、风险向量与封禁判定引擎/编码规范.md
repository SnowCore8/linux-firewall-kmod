- 纯计算函数（如 `ClassifyFailure`、`Deviate`、`countRecent`）不持有状态、不访问 IO，仅接收输入参数并返回结果，以便独立单元测试。
- 对外暴露的错误使用包级 `var` 预声明的哨兵错误值（如 `ErrCidrEmpty`、`ErrCidrInvalidPrefix`），调用方通过 `errors.Is` 判断而非比较字符串。
- 需要稳定标识符的类型（如 `CidrKey`、`EventType`）通过构造函数（`NewCidrKey`、常量）构造，零值被设计为无效，避免「未归一化」状态逃逸到上层。
- 面向 JSON 载荷的内部结构体命名与契约层分离：分析结果用 `PeriodicAttackFinding`/`CollaborativeAttackFinding` 等本地名，注释明确说明契约形状由 `internal/http` 承载，避免跨包字段名耦合。
- 可变集合在返回前拷贝副本（如 `append([]int64(nil), timestamps...)`、`percentile` 中对列切片 `append` 后再排序），防止调用方修改内部状态。
- 数值型配置参数在函数入口集中做默认值兜底（如 `minEvents < 3` 时置 3、`limit <= 0` 时置 20），保证调用方可省略可选参数。
