模块由三个相互独立的子包构成，依赖方向单向：`detect` → `analysis` / `risk`，三者均不互相引用。

- `internal/detect`（纯计算层）：提供无锁、可并发复用的基础构件。`window.go` 中的 `FailureWindow` 维护每个 IP 的固定长度时间戳 FIFO 队列，按 `findtime` 窗口统计失败次数并返回 `Verdict`；`cidr.go` 定义不可变 `CidrKey` 类型对 CIDR 文本做归一化（网络位清零、裸地址补 `/32`/`/128`），对外暴露强类型键而非裸字符串。
- `internal/risk`（风险向量引擎）：`types.go` 定义七维 `RiskVector`（failure/ban/scan/bruteforce/ddos/geo/cluster）及 `DimensionWeights`；`decay.go` 给出半衰期 7 天的指数衰减函数；`classifier.go` 把日志事件类型 + payload 映射为 `EventType` 与增量；`engine.go` 的 `Engine` 是带 `sync.RWMutex` 保护的内存缓存（LRU 风格，5 分钟过期），对外提供 `RecordEvent`/`GetVector`/`ShouldBan`，采用加法模型的有效阈值 `baseThreshold + peakAddend + internalAddend + reputationAdjustment`。
- `internal/analysis`（离线分析层）：`detection.go` 从 `persist.DB` 拉取封禁事件，分别计算周期性攻击（变异系数 cv < 0.3 视为周期）和协同攻击（滑动窗口内唯一 IP ≥ minIPs）；`anomaly.go` 基于 p50/p95 分位数基线计算全局与 per-IP 偏离度；`ewma.go`/`network.go`/`prediction.go` 提供 EWMA 平滑、网络特征与预测辅助；`recommendations.go` 输出面板建议。

分析层直接依赖 `persist.DB` 读取历史事件，风险层通过 `Engine` 持有状态，检测层保持纯函数式——三者边界清晰，便于单测替换数据库或注入时间。
