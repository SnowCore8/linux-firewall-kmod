模块按职责划分为四层：
- 顶层 `threatfeeds` 包（manager.go / cache.go / scheduler.go / http.go / config.go）负责编排：`FeedManager` 通过 `buildSource` 根据配置名分发到具体适配器；`RefreshAll` 用 `sync.WaitGroup` + buffered channel 并发刷新所有源并聚合结果；`FeedCache` 以 RWMutex 保护 map，Merge 时先构建新 map 再原子替换，Lookup 先精确匹配再 CIDR 遍历；`Scheduler` 基于 ticker + jitter 防惊群触发刷新。
- `sources/` 子包定义 `FeedSource` 接口（Name/URL/Parse），每个文件（ipsum/firehol/dshield/blocklist/feodo）实现一个适配器和对应格式的 `Parse`，共享 `parseIPList` 通用行解析器。
- 类型边界：`types.go` 暴露 `RefreshResult`、`FeedStats`；`manager.go` 通过 `type FeedEntry = sources.FeedEntry` 别名避免循环依赖，仅把 `FeedSource` 接口向上暴露给上层。
- 依赖方向单向：manager → sources/http/cache/scheduler，sources 不反向引用 manager。
