模块以 `db.go` 中的 `DB` 结构体为核心，封装 `*sql.DB`、`slog.Logger` 与数据库路径，并通过 `Config` + `NewDB` 构造；启动时执行 `migrate()`：先 `CREATE TABLE IF NOT EXISTS` 建表，再按版本号顺序调用 `applyMigrations()` 执行增量迁移（当前仅 v1），并通过 `schema_migrations` 表记录已应用版本。

领域按文件拆分，每个文件对应一张核心表或一组相关查询：
- `ban_events.go` / `history.go`：封禁事件明细与 IP 维度的封禁历史聚合
- `reputation.go`：IP 信誉分（score/last_failure/last_ban/total_*）的 upsert、衰减恢复与低信誉查询
- `attack_events.go`：攻击事件时间序列
- `risk_vectors.go`：多维风险向量（failure/ban/scan/bruteforce/ddos/geo/cluster）快照，依赖上层 `internal/risk` 包做衰减计算
- `activity.go`：面向统计面板的只读查询（趋势、热力图、今日窗口），注释明确该面只读，写由 `CleanupExpired` 定时任务负责
- `recovery.go`：信誉恢复调度器入口

所有查询使用参数化 SQL（`?` 占位符），标识符（表名、列名）仅在 `ensureColumn` 中以常量拼接，避免注入；连接池限制为单连接（`SetMaxOpenConns(1)`）并开启 WAL、NORMAL 同步与 5s busy_timeout。后台任务通过 `StartXxxScheduler(interval, ..., stopCh)` 模式暴露，内部用 `time.Ticker` + `select` 监听 stop channel。
