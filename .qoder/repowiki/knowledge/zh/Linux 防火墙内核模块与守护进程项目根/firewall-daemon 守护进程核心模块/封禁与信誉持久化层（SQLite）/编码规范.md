- 对外暴露的 DB 方法统一返回 `(value, error)`，错误通过 `fmt.Errorf("...: %w", err)` 包装原始错误以便调用方判断。
- 批量读取采用 `rows.Next()` 循环 + `defer rows.Close()` + 末尾检查 `rows.Err()` 的标准模式，并在 Scan 失败时包装错误。
- 可选字段（如 `LastFailure`、`LastBan`、`IsPermanent`）在扫描时使用 `sql.NullInt64` 或 `int` 转 bool 的方式处理 NULL/零值语义。
- 写操作普遍使用 SQLite 的 `INSERT ... ON CONFLICT(ip) DO UPDATE SET ...` 实现 upsert，避免先查后写的竞态。
- 后台定时任务统一以 `StartXxxScheduler(interval, params..., stopCh <-chan struct{})` 形式暴露，内部起 goroutine 用 `time.NewTicker` + `select` 监听 stop channel。
- 默认参数通过函数内 `if x <= 0 { x = default }` 赋值而非重载，多个方法对 interval/recoveryRate/maxScore/threshold/limit 均采用此模式。
