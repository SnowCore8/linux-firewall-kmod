模块按四层自底向上组织，共享同一个 netlink fd：
- transport（transport.go）：底层 I/O 层，直接调用 golang.org/x/sys/unix 创建 AF_NETLINK SOCK_RAW socket，维护 epoll + eventfd 就绪观察、SO_RCVTIMEO 阻塞接收、nlmsghdr 编解码与链路健康计数器（CounterMessagesSentTotal/ReceivedTotal/SendErrorsTotal/RecvErrorsTotal），对外暴露 Send/TryRecv/Poll/Subscribe/Close。
- router（router.go）：纯状态机，把 Datagram 按 MsgType 分派到「在途请求 replyHandle」或「Incoming 事件通道」；pendingTable 以 (msg_type, seq) 为键管理最多 MaxInFlight=64 条在途请求，提供 Register/Claim/Abandon 语义并统计 unmatchedReplies/pendingFull/seqCollisions 等计数。
- reactor（reactor.go）：I/O 驱动循环，Poll(EventRx|EventLinkDown) → drain() 排空 socket → Router.HandleDatagram，负责错误退避与 shutdown 协作。
- client（client.go）：类型化请求客户端，封装 allocSeq + exchangeWith(requestType, payload, timeout)，向上暴露 QueryStats/QueryAnalysis/SetConfig/Register/Ban/Unban/List* 等 API，Ban/Unban 等单向命令返回 Delivered 而非执行确认。
- consumer（consumer.go）：事件泵 EventPump，组合根装配 Sampler/Store/Ring/Cache/Whitelist/Publisher/Mirror/Metrics，按 SampleInterval(5s)/ReconcileInterval(30s)/RegisterInterval(10s) 周期采样三张表、对账封禁镜像、主动续约守护进程租约，并通过 DomainMirror 把 bans/whitelist/stats/rates 域变更推送给 http.SSEBroker。

依赖方向严格单向：consumer → client → router → transport；consumer 通过 Sampler/Publisher/DomainMirror/Metrics 接口反向解耦 http 与 telemetry 包，避免 kernel 层被上层反向引用。codec.go 集中所有 contract.Header 与 MsgType 的 Decode 分支，是协议契约的唯一入口。
