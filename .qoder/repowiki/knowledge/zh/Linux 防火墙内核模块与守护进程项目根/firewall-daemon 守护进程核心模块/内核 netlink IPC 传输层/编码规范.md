- netlink 报文长度校验遵循两层：Transport.TryRecv 用 MSG_TRUNC 检测截断并按 nlmsghdr.nlmsg_len 校验完整性，Router.decodeHeader 再校验魔数与 msg_len == len(payload)，两者缺一不可。
- 在途请求通过 Router.Register 登记后由 Client.exchangeWith 先发送再 RecvTimeout 等待，超时或失败路径显式调用 replyHandle.Abandon 释放 pending 条目，防止 (type, seq) 泄漏。
- 链路断开通过 Transport.SignalLinkDown 同时关闭 linkDown chan 与写入 wakeFd，使 epoll_wait 与 select 两条等待路径都能立即返回 EventLinkDown。
- 周期性行为（SampleInterval/ReconcileInterval/RegisterInterval/shutdownPollInterval）以包级 const 声明且不可配置，注释明确其取值由内核侧固定语义决定。
- 面向上层的扩展点（Sampler/Publisher/DomainMirror/Metrics）以接口形式注入，kernel 包不直接依赖 http 或 telemetry 的具体实现，保持单向依赖。
- 所有可观测指标通过 CounterHandle.Add(1) 累加，Transport 与 EventPump 分别维护各自命名空间（firewall_netlink_* / firewall_ddos_events_total / firewall_kernel_commands_rejected_total），零值句柄时 bumpCounter 跳过计数。
