本包是 Go 可执行 `firewall-daemon` 的组合根（`main.go`），遵循「组合根只装配与生命周期、不含业务判定」的约定：
- 启动流程：解析 CLI → 校验面板静态资源 → 可选回滚短路径 → 初始化信号层 → 加载 YAML/目录配置 → `jail.Finalize` 后处理 → 初始化日志 → 安全审计（监听地址 + 出厂口令告警）→ 检查 `/proc/firewall` → 按依赖顺序装配各子系统。
- 子系统通过 `runtime.Supervisor` 以命名 token 注册并统一关停，关停顺序按登记逆序（LIFO defer）保证入站主链路先于内核接收回路收尾。
- 对外暴露三类 sink 适配器（`banSink` / `whitelistSink` / `configSink`）把 HTTP API 与入站执行体的下发请求桥接到 `internal/kernel.Client`，并在内核缺失时降级为无操作。
- 通过 `kernelMetrics` / `jailSnapshotBridge` 等薄壳解耦 `internal/http` 与 `internal/kernel`，避免双向循环依赖。
- 辅助文件 `bind_address.go` 提供仅基于字面量的非 DNS 解析监听地址判断，供安全告警使用；测试文件覆盖该函数与主入口参数解析行为。
- 依赖方向单向向外：本包依赖 `daemon/internal/{config,kernel,http,persist,bans,runtime,telemetry,threatfeeds,jail,logger}`，不被它们反向引用。
