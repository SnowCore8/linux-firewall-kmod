- 每个消息结构体都配套一个 offXxx map[string]int 偏移表，并在 wireLayouts 中声明 size 与引用该偏移表，Decode/Encode 统一通过该表访问字段。
- 所有多字节整数一律通过 getU16/getU32/getU64 与 putU16/putU32/putU64 在固定偏移上读写，禁止把 Go 结构体直接映射到字节切片以避免对齐填充。
- 字符串字段使用定长 NUL 结尾布局：写入走 putStr（超长报错），展示用 ClampFixedString（UTF-8 安全截断），读取走 getStr。
- 每条 Decode 方法先调用 ParseHeader 校验魔数与 msg_len，再断言 h.MsgType 与报文总长度等于 wireLayouts[Name].size，任一不符返回错误。
- 分页响应（ListBansResponse/ListWhitelistResponse/ListRatesResponse）通过 MaxTailEntries() 依据 MsgLenMax 与元素大小计算单页上限，Encode 时拒绝超限条目。
- 共享载荷（SetConfig 与 ConfigChange、AddWhitelist 与 RemoveWhitelist、BanIp 与 UnbanIp）复用同一 offXxx 偏移表与 encodeConfigPayload/decodeConfigPayload 辅助函数，保证两端布局一致。
