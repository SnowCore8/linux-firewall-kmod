模块按职责拆分为四个文件：`jail.go` 提供 `Validate`/`ClusterWarning`/`JoinErrors` 等纯校验工具；`service.go` 维护 SSH/WEB/FTP/MAIL/FRP/DB 六类服务名模式表与 `ApplySmartDefaults`，通过 `IsServiceNameMatch` 做 `-` 分隔的整词匹配推断阈值；`compile.go` 负责正则生命周期（注入内置 sshd 模式 → 调用 `logparse.ValidateRegexSafety` 做 ReDoS 启发式检查 → `regexp.Compile` → `BuildRuleSet` 产出不可变规则集）；`pipeline.go` 暴露唯一对外入口 `Finalize`，把三步（智能默认→校验→编译）固定顺序封装为幂等流程。

依赖方向单向向外：仅依赖 `daemon/internal/config`（读取/回填结构体字段）与 `daemon/internal/logparse`（正则安全校验与规则构造），不反向被 config 或 logparse 引用。所有函数以 `*config.Config` / `*config.Jail` 指针就地修改，由上层启动/重载流程控制时序。
