- 长驻资源（fd、读缓冲、半行缓冲）挂在「源」级别而非事件级别，避免每次事件重分配 256 KiB 缓冲。
- 对内核 fd 的操作统一通过 `golang.org/x/sys/unix` 直接调用，错误处理区分 EINTR/EAGAIN 等可重试软失败与致命错误。
- 跨协程边界只传递不可变值对象（`Chunk`、`WatchEvent`），被调方不得持有调用方的缓冲切片所有权。
- 解析路径采用「廉价预检 → 昂贵校验」的两阶段策略：长度窗口、首字节 hex 检查先行，完整正则或 IP 解析后置。
- 用户可控的正则表达式在编译前经 `ValidateRegexSafety` 静态检查，限制长度、分支数与危险语法组合。
