- 所有二进制结构体采用 packed 布局，字段按声明顺序紧排，空隙必须显式写 `u8[N]`，禁止依赖编译器对齐产生隐式填充。
- IDL 中的枚举取值唯一且落在底层宽度内、位标志序号唯一且不越界、消息总长不超过 u16 上限，校验失败直接抛 `ContractError` 终止生成。
- 变长消息统一以名为 `tail` 的单个 struct 字段标记尾部元素，其容量通过 `(MSG_LEN_MAX - fixed) / elem_size` 计算并在 C/TS/JSON 三处同时输出。
- 生成的 C 结构体末尾附带 `_Static_assert(sizeof(struct fw_xxx) == N, ...)`，使布局漂移在编译期暴露。
- HTTP 契约的每条 `route` 必须在 `routes.go` 中以逐字一致的 `"METHOD /path"` 注册，handler 符号也需一致，注册串本身即锚点，不再维护位置索引。
- 缺陷记录使用 `status = open | fixed | retained` 表达处置结论：open 要求 where 仍存在，fixed 要求 where 消失且 fix 存在，retained 要求 where 指向源码中「有意保留」注释。
