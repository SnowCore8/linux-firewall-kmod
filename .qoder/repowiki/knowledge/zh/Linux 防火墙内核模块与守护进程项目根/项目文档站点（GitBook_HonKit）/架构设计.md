文档站点采用 HonKit 静态书生成器：顶层 `book.json` 定义书名、语言（zh-hans）、侧边栏链接及 SUMMARY/README 入口；`LANGS.md` 声明多语言支持（当前仅 zh）；`zh/SUMMARY.md` 作为书籍目录，将内容组织为简介、快速开始、配置指南、架构设计、运维管理、开发指南六大章节，每章以独立 README 作为子目录入口，配套若干专题 Markdown 文件（如 architecture/kernel-module.md、configuration/yaml-config.md、development/testing.md）。构建产物由 HonKit 渲染为静态 HTML，无运行时代码。依赖通过 `package.json` 锁定 honkit ^6.1.7，并通过 overrides 修复 tmp、qs、undici、brace-expansion、moment 等下游安全漏洞。
