# Getting Started

This section guides you through installing and configuring the Linux Firewall Kernel Module.

## Workflow

1. Verify your system meets the [requirements](installation.md#system-requirements)
2. [Install](installation.md) the kernel module and daemon
3. Configure your first jail following the [Quick Start](quick-start.md)
4. Verify the banning functionality works correctly

## Prerequisites

Using this project requires knowledge of:

- Basic Linux command line operations
- Basic concepts of kernel modules
- Log file formats and regular expressions
